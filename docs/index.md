# LGTM

## Learn through code review

LGTM is a code review academy. Learners review pull requests with planted
flaws and get AI-graded feedback on their reviews.

## Three roles, one academy

### Learner

Review pull requests with planted flaws and get AI-graded feedback on your
review.

### Author

Turn working code into challenges by having AI inject flaws.

### TA

Moderate AI grades and see AI summaries of learner blind spots.

Code submitted to the app is displayed, never executed.
